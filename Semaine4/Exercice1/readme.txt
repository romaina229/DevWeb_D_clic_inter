Explication : code bonjour tout le monde
Le mot-clé echo affiche du texte dans le navigateur.
Le script PHP est délimité par <?php et ?>.
Quand le serveur exécute la page, il envoie le texte au navigateur.
Lorsque vous ouvrez cette page dans un navigateur, vous verrez "Bonjour le monde !" affiché à l'écran.
